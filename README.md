# TeachMe Store

Live site: https://prevoda1.github.io/teachme-store/

Public repo: https://github.com/prevoda1/teachme-store

Static educator fashion store with shop filters, LocalStorage cart, promo code EDUCATOR15, and AI Style Mentor demo looks.

If the Pages URL 404s for a minute, open **Settings → Pages** and set Source to **GitHub Actions**, or Source to **Deploy from a branch → main / root**.
